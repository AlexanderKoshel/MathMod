Из корня MathMod:

```powershell
python -m pip install -r lab-02/requirements.txt
python lab-02/lab2.py
```

`--seed` задаёт seed; `--repetitions` — число повторений (по умолчанию 5000).
Геометрическое распределение по умолчанию считает испытания до успеха, носитель 1,2,…; для числа неудач используйте `--geometric-start 0`.
