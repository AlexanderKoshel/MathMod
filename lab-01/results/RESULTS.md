# Лабораторная работа 1. Вариант 10

## Задание и параметры

Моделирование базовой случайной величины с распределением U[0,1). По 1000 реализаций МКМ и метода Макларена–Марсальи; α = 0,05.

a₀ = β = 16807; M = 2³¹ = 2147483648; K = 64.
Второй датчик: Python random.Random (Mersenne Twister), seed = 2026.
МКМ для обоих экспериментов создаётся заново с одинаковыми a₀ и β. В смешанном генераторе первые K значений заполняют таблицу; далее они выдаются и заменяются по индексам второго датчика.

## Алгоритмы

МКМ: aᵢ = (β·aᵢ₋₁) mod M, xᵢ = aᵢ/M; первым выдаётся a₁/M.

Макларен–Марсалья: T[j] заполняется K числами МКМ. На каждом шаге получаем y от второго датчика, j = floor(K·y), выдаём T[j] и заменяем T[j] следующим числом МКМ. При y ∈ [0,1) индекс находится в 0,…,K−1.

## Проверка согласия

H0: распределение соответствует U[0,1); H1: распределение отличается. Для каждого критерия отдельно используется уровень значимости 0,05.

Колмогоров: D⁺ = max(i/n − x₍ᵢ₎), D⁻ = max(x₍ᵢ₎ − (i−1)/n), D = max(D⁺, D⁻), i = 1,…,n. Критическое D и p-value вычисляются по конечновыборочному распределению scipy.stats.kstwo.

Пирсон: [0,1) делится на 10 равных интервалов, левая граница включена, правая исключена. Ожидаемая частота в каждом — 100. χ² = Σ(Nⱼ − 100)²/100. Число степеней свободы: 10−1 = 9, так как параметры равномерного распределения не оценивались по выборке.

Правило решения: отвергнуть H0, если p-value < 0,05 (эквивалентно превышению критического значения).

## Вывод

- MKM: Колмогоров — Нет оснований отвергать H0; Пирсон — Нет оснований отвергать H0.
- MacLaren-Marsaglia: Колмогоров — Нет оснований отвергать H0; Пирсон — Нет оснований отвергать H0.

Критерии исследуют согласие одномерного распределения. Отсутствие отклонения H0 не доказывает независимость, идеальную случайность или превосходство одного датчика. Калибровка критериев предполагает независимую выборку из непрерывного распределения; для дискретных псевдослучайных последовательностей это стандартная диагностическая модель.
