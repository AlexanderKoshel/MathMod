# Лабораторная № 1 — вариант 10

Проект реализован одним Python-модулем; численные результаты сохранены в Git. Исходный код не изменяется.

## Архитектура

Python → main → run → два генератора → take → analyze → CSV/JSON → plot_samples → save_report → печать в консоль. Генераторы используют отдельные состояния МКМ, но одинаковые параметры. Селектор смешанного метода — random.Random(2026). Вычисления отделены от оформления функциями, а не отдельными модулями.

## ФАЙЛ: lab1.py

**КАКИЕ ФУНКЦИИ ВЫПОЛНЯЕТ:**

| Функция | Вход | Действие и выход |
|---|---|---|
| multiplicative_congruential | seed, multiplier, modulus | Проверяет диапазон; бесконечно обновляет состояние по модулю и выдаёт нормированное число через yield |
| maclaren_marsaglia | source, selector, table_size | Заполняет таблицу, выбирает индекс, выдаёт старое значение, заменяет его новым |
| take | generator, count | Получает count значений вызовами next |
| analyze | sample | Проверяет диапазон и объём, сортирует, вычисляет описательные статистики, D и χ², возвращает словарь |
| decision | reject | Преобразует булево решение в текст |
| plot_samples | samples, out | Строит фигуру 2×2, сохраняет PNG и закрывает фигуру |
| save_report | out, parameters, results | Формирует строки Markdown, таблицы и вывод |
| run | variant, selector_seed, out | Координирует расчёт, создаёт каталог, записывает результаты |
| main | аргументы CLI | Разбирает параметры, вызывает run, печатает статистики |

Константы: MODULUS=2**31, N=1000, ALPHA=0.05, BINS=10; VARIANTS содержит пары (a0,K) для 16 вариантов, beta=a0.

**КАКИЕ ИСПОЛЬЗУЕТ МЕТОДЫ БИБЛИОТЕКИ:**

- argparse: ArgumentParser, add_argument, parse_args — интерфейс командной строки.
- csv: writer, writerow, writerows — табличный экспорт.
- json.dumps — сериализация вложенных словарей.
- math.sqrt — масштабирование статистики Колмогорова.
- random.Random и random() — второй псевдослучайный генератор.
- pathlib.Path: resolve, mkdir, open, write_text — файловый ввод-вывод.
- statistics.fmean и variance — среднее и несмещённая дисперсия.
- matplotlib.use("Agg") — неинтерактивный backend; pyplot.subplots, hist, step, plot, axhline, set_xlim, legend, grid, savefig, close — построение графиков.
- scipy.stats.kstwo и chi2: ppf — квантиль; sf — вероятность правого хвоста.
- Встроенные next, yield, sorted, enumerate, max, min, sum, int, zip — итерация и расчёты.

**ЗАВИСИМОСТИ И ВЗАИМОДЕЙСТВИЯ:** стандартная библиотека и два внешних пакета; собственных импортируемых модулей нет. run передаёт выборки в analyze и plot_samples, словари статистик в save_report. main вызывается только при прямом запуске файла.

## Запуск и проверка (PowerShell, из корня репозитория)

```powershell
cd lab-01
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe lab1.py --variant 10 --selector-seed 2026 --out results-check
```

Ожидаются D=0.025725 и 0.023725, χ²=7.3 и 7.6; четыре файла в results-check. Фактический повторный запуск в текущем сеансе не выполнялся: значения взяты из сохранённого summary.json.

## Правила дальнейшей работы

Не смешивать состояние двух генераторов. Сохранять интервал [0,1), фиксированные параметры варианта, проверку ожидаемых частот, уровень значимости и явный seed. При изменении алгоритма обновлять результаты, отчёт, теорию и данный файл. Не трактовать отсутствие отклонения H0 как доказательство независимости.
