# Лабораторная 4 — вариант 10

Источник: оригинал «Лабораторная работа 4.doc» в этой папке. Встроенные формулы извлечены как изображения и проверены визуально.

- [x] Прочитать оба интеграла варианта 10: exp(−x⁴)√(1+x⁴) на всей прямой; 1/(x²+y⁴) на кольце 1≤x²+y²<4.
- [x] Реализовать выборку по значимости с плотностью Коши для бесконечного интервала.
- [x] Реализовать равномерные по площади точки кольца через R=√(1+3U).
- [x] Получить эталоны квадратурами; независимо проверить I₁ через специальную функцию и I₂ через точную формулу.
- [x] Рассчитать оценки, фактические ошибки, стандартные ошибки и приближённые 95% интервалы для ряда n до 10⁶.
- [x] Выполнить запуск до n=1000000, проверить преобразованный интеграл квадратурой, формулу углового интеграла, моменты равномерного кольца и расчёт стандартной ошибки; сохранить и визуально проверить график зависимости точности от n.

Запуск из корня MathMod:

```powershell
python -m pip install -r lab-04/requirements.txt
python lab-04/lab4.py
```

`--seed` задаёт начальное состояние; `--max-n` — максимальное число реализаций (по умолчанию 1000000).
Результаты: `results/RESULTS.md`, `summary.json`, `estimates.csv`, `convergence.png`.
